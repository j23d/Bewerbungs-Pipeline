# Nachweise (Zeugnisse, Zertifikate)

Lege hier deine PDF-Nachweise ab: `*.pdf`

Diese Dateien belegen Aussagen im Masterprofil. Die Pipeline referenziert sie
für Zertifikate/Qualifikationen. Es werden keine Inhalte erfunden — nur was hier
(bzw. im Masterprofil oder im Lücken-Dialog) belegt ist, darf verwendet werden.

Beispiele:
- `zeugnis_bachelor.pdf`
- `zertifikat_aws.pdf`
- `arbeitszeugnis_firma-x.pdf`
